# لوحة الكشف المتعدد (React + FastAPI + Hugging Face)

مشروع لكشف:
- عدّ الأشخاص (موديل **CrowdHuman YOLOv8** — مخصص لكشف الأشخاص والزحام)
- الدخان
- الحريق
- السقوط / الطوارئ
- اتجاه مشي الأشخاص (أخضر = صح، أحمر = غلط، أصفر = يتتبع)

---

## المتطلبات

- **Node.js** (مع npm)
- **Python 3.11+**
- اتصال إنترنت لأول تشغيل (لتنزيل موديلات Hugging Face)

---

## التثبيت (مرة واحدة فقط)

### 1) الواجهة

افتح الطرفية في مجلد المشروع ثم:

```bash
npm install
```

### 2) سيرفر بايثون

```bash
cd server
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
cd ..
```

اختياري: انسخ `server/.env.example` إلى `server/.env` وضع `HF_TOKEN` إن احتجت تحميل أسرع من Hugging Face.

---

## التشغيل

### الطريقة الأسهل (ويندوز)

اضغط مرتين على الملف:

```
start.bat
```

يفتح السيرفر والواجهة معاً.

### أو من الطرفية

من مجلد المشروع:

```bash
npm run dev:all
```

هذا الأمر يشغّل:
- API على: http://127.0.0.1:8010
- الواجهة على: http://localhost:5173

افتح المتصفح على:

**http://localhost:5173**

---

## تشغيل يدوي (طرفيتين)

**طرفية 1 — السيرفر:**

```bash
cd server
.venv\Scripts\activate
uvicorn main:app --reload --host 127.0.0.1 --port 8010
```

**طرفية 2 — الواجهة:**

```bash
npm run dev
```

## طريقة الاستخدام

1. فعّل الموديلات اللي تبغاها من الأزرار أعلى الصفحة.
2. لاتجاه المشي: اختر الاتجاه الصحيح (أعلى / أسفل / يسار / يمين).
3. افتح الكاميرا، أو ارفع صورة/فيديو.
4. راقب النتائج والتنبيهات في اللوحة الجانبية.

**ملاحظة:** أول استخدام لكل موديل قد يتأخر قليلاً بسبب تنزيل الأوزان من Hugging Face.

## حل مشاكل سريعة

**الواجهة تقول السيرفر غير متصل**
- تأكد أن المنفذ 8010 شغال
- أعد التشغيل: أوقف الطرفية (Ctrl+C) ثم `npm run dev:all`

**منفذ مشغول / WinError**
- أغلق أي تشغيل قديم للمشروع
- أو غيّر المنفذ في `package.json` و`vite.config.js`

**الموديلات بطيئة أول مرة**
- طبيعي: يتم تنزيلها من Hugging Face ثم تُحفظ محلياً
